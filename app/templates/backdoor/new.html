Statically Analyze a Local Directory

PwnBroker will use Backdoor Detector to check a directory already on this server for YARA-matched malware/backdoor signatures, hardcoded secrets, and vulnerable dependencies.

Read-only — nothing in the directory is ever executed
This tool has an optional "runtime analysis" mode upstream that auto-detects and runs a project's entry point to watch its network behavior. PwnBroker never uses that mode — only static analysis (YARA signatures, hardcoded-secret patterns, and dependency vulnerability checks) runs, so nothing on disk is ever executed.
Only Local Path-type targets appear here. + Add a Local Path target
What this scans
  • YARA signature matching against every file (malware packers, process injection, anti-debugging, backdoor keyword patterns)
  • Hardcoded API keys, passwords, tokens, private keys, and AWS/SSH credentials in source files
  • Vulnerable dependencies via Safety, Trivy, pip-audit, and npm audit (whichever are installed — missing ones are skipped)
  • Capped at 10 minutes; unlike other scan types here, results are only available once the whole run finishes — a timeout returns no partial findings
