Map Active Directory Attack Paths

PwnBroker will collect Active Directory relationship data with bloodhound-ce-python, upload it to your BloodHound CE instance, and run a fixed set of attack-path hunting queries against it — Kerberoastable accounts, AS-REP roastable accounts, unconstrained delegation, DCSync rights, and shortest paths to Domain Admins / Enterprise Admins.

This can take a while
Collection alone can take up to 30 minutes against a large domain, and BloodHound CE needs time to ingest and analyze the result afterward. The scan stays "running" the whole time — no partial findings appear until analysis finishes.
Only AD Domain-type targets appear here, with domain-collection credentials already configured. + Add an AD Domain target
What this scans
  • Full AD collection (users, groups, computers, ACLs, sessions, GPOs, trusts) via LDAP/SMB/RPC against the domain controller — no agent needed on domain-joined hosts
  • Kerberoastable and AS-REP roastable accounts, escalated to critical if the account also has DCsync-style admin rights (admincount)
  • Computers trusted for unconstrained delegation, excluding domain controllers themselves
  • Principals with DCSync replication rights outside the expected built-in admin groups
  • Shortest attack paths to Domain Admins and Enterprise Admins across the standard set of abusable AD relationships
